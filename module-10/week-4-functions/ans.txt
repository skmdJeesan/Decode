Q: The minimum number of functions present in any C++ program is: (1) 0, (2) 1, (3) 2, (4) infinite
ans: 1, Every C++ program must have at least one function, which is: main()

Q: State True and False:
1. A function may be called more than once from any other function - True, it is true fact
2. It is necessary for a function to return some value. - False, void functions does not return any value

Q: Can the same function name be used for different functions without any conflict?
ans: yes, the same function name can be used for different functions using function overloading, provided that the functions have different parameter lists. The return type alone cannot differentiate functions.
